This interactive tutorial will teach you the basic building blocks to start building great apps with Angular.

1. Component's decorator properties
2. HTML templates - interpolation - You can use this syntax to put dynamic text, call functions, write expressions and more.
3. Reference one component in another (see app.component code & template).
4. Deciding what to display: Conditional control Flow in Components - a-if a-else (Angular template syntax) v17+
5. Repeat some template code - Control Flow in Components - a-for
6. Property binding in templates: dataClass properties: set values for properties and attributes of html elements, Angular components and more.
7. Event handling (& responding to user actions)
8. a-Input: sending data into a component (from parent to child, using attributes of child component)
9. a-Output: event communication with parent component (emitting events or sending data to parent component using events & event subscriptions)
10. Deferrable views - how to defer load a section of your component template
11. Optimizing images - NgOptimizedImage
12, 13. Routing Overview
14. Forms - template-driven approach & "banana in a box"
15. Forms - Reactive Forms
16. Validating forms
17. Services - Creating an injectable service
18. Pipes

20. Pipes - Create a custom pipe
